# Release validation — 1 October 2026

The native Python 3.12 edition passed **76 Python tests** and **six Node animation checks**. All 22 authored practical solutions passed both scenarios. All 11 SQL connections executed in both fixture scenarios. The UI test completed prediction, notebook, real query, randomized assessment, badge, and next-mission progression, and rendered all 22 mission pages.

The browser review covered the checkout animation, the first Streamlit prediction, rate/irate stepping and controls, trace teaching, written alternatives, and the public playground at desktop and 390px mobile width. The mobile page width matched the viewport; large diagrams intentionally allow horizontal swiping within their own panel. The studio screenshot and rate/irate screenshot in `assets/` were captured from the working product, not generated mockups.

The HTTP test ran three actual loopback services and decoded exported OpenTelemetry protobuf. It checked three spans, one shared trace ID and two parent relationships. No official Collector process or Docker runtime was available for local deployment verification; Docker is supplied as a deployment option, not claimed as locally exercised.

Live provider checks accepted Nebius inference, Pinecone search over a new dedicated index containing 70 public course excerpts, and a structured Gemini 3.8 Flash response. The final six-case grounded tutor smoke run used BM25 plus Pinecone for every case, returned valid course citations for all six, generated five answers with Nebius, and correctly retained an authored course fallback for one case. Gemini's older 2.5 model returned an unavailable-model error and was replaced with the account-supported 3.8 model. A subsequent p95 safeguard check rejected unsupported invented numerical claims, returned an accurate Gemini fallback, and completed a Braintrust metadata-only flush. The tutor does not fail learning if that optional logger is unavailable.

The smoke questions check counter/gauge meaning, latest-two-sample rate, sum of gauge snapshots, cumulative buckets, aggregate p95, and trace propagation. Expected facts are versioned in `evals/tutor_cases.json`. Valid citation IDs are a structural check, not an automated assertion of every factual claim. Review the answer's expected facts when rerunning a live evaluation. Provider outputs can vary.

Testing found two substantive model errors in the earlier evaluation: invented interpolation within an unbounded histogram bucket and a gauge-persistence overclaim. The release uses authored worked examples, an explicit domain instruction, targeted misconception rejection, schema and citation validation, and a course fallback. These measures reduce identified errors; they do not make generative explanations infallible.

The publication scan compared every included file against the configured credential values and excluded `.env`, `.runtime`, installed engines, private databases and recovery codes. The playground contains no provider keys or backend calls. Human learning effectiveness, conversion, retention gains and job readiness have not yet been measured. See `learner-review.md` for the beginner audit and pilot questions.
